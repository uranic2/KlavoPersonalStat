Как считаются результаты

Месяц — с той же даты предыдущего месяца до сегодняшнего дня включительно, по московскому времени. Сегодняшний день — по момент обновления. При одинаковой максимальной скорости показан первый день. «—» означает отсутствие результата в открытой статистике; «Не загружено» — этот словарь ещё не обновлялся. Скорость не фильтруется по ошибкам и сама по себе не подтверждает прохождение учебной программы. Во «Всех словарях» пересечения между группами учитываются один раз.

Кнопка «Обновить» загружает статистику выбранной группы. Во «Всех словарях» обновляются все группы. При ошибке прежние данные сохраняются. Каталоги встроенных групп сохранены из первых сообщений тем; импорт своей группы также читает первое сообщение.
